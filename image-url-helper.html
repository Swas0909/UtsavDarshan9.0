🖼️ Image URL Helper

Quick tool to get image URLs for your pandal website

📤 Method 1: Upload to Image Hosting Service

Recommended Services:

📸 Imgur (Easiest) 📸 ImgBB ☁️ Cloudinary
  1. Click on one of the services above (Imgur recommended)
  2. Upload your pandal image
  3. Right-click the uploaded image → "Copy image address"
  4. Paste the URL in the field below

📁 Method 2: Use Local Images

  1. Save your image file (e.g., lalbaugcha-raja.jpg)
  2. Copy it to: client/public/images/pandals/
  3. Use path: /images/pandals/lalbaugcha-raja.jpg
Example:
File location: client/public/images/pandals/andheri-raja.jpg
Database value: /images/pandals/andheri-raja.jpg

💾 Update Database with SQL

After getting your image URL, update your database:

Option 1: By Pandal ID
UPDATE pandals SET image_url = 'YOUR_IMAGE_URL' WHERE id = 1;
Option 2: By Pandal Name
UPDATE pandals SET image_url = 'YOUR_IMAGE_URL' WHERE name LIKE '%Lalbaugcha%Raja%';
💡 Tip: Use pgAdmin or psql command line to run these SQL commands on your PostgreSQL database.
